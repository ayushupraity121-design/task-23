# Task 23: Duplicate Data Removal

An AI & ML track mini-project focused on identifying and removing duplicate records in a dataset using Pandas before analysis and modeling.

---

## 📌 Objective
Learn basic data-cleaning techniques to handle duplicate entries, assess dataset integrity, and compare row counts before and after cleaning.

---

## 🛠️ Tools Used
* **Python 3.x**
* **Pandas**
* **Jupyter Notebook / VS Code**

---

## 📋 Deliverables
1. **Number of Duplicate Records:** Identified using `df.duplicated()`.
2. **Cleaned Dataset:** Obtained using `df.drop_duplicates()`.
3. **Before-and-After Row Counts:** Compared and printed.
